# E-Commerce SQL Case Study

## Project Overview

This project analyzes an e-commerce dataset using SQL to uncover insights related to customer behavior, product performance, sales trends, and business growth.

## Dataset

The analysis is based on four tables:

- Customers
- Orders
- Products
- OrderDetails

## Business Questions Solved

1. Data Analysis
2. Market Segmentation Analysis
3. Engagement Depth Analysis
4. Purchase High Value Products
5. Category-wise Customer Reach
6. Sales Trend Analysis
7. Average Order Value Fluctuation
8. Sales Frequency Per Product
9. Low Engagement Products
10. Customer Acquisition Trend
11. Peak Sales Month Identification

## SQL Skills Demonstrated

- Joins
- Common Table Expressions (CTEs)
- Window Functions
- Aggregate Functions
- Date Functions
- Ranking Functions
- Business Analysis
